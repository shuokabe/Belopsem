# Belopsem_France

## About
This folder contains **Belopsem_France**, the BUCC-style datasets for regional languages of metropolitan France.
There are six files per language pair: three files (`source_lang|target_lang|gold`) for each set (`train|test`).

Belopsem_France covers the following six language pairs (a regional language paired with French):
- Breton–French (`bre-fr`)
- Corsican–French (`cos-fr`)
- Basque–French (`eus-fr`)
- Alsatian–French (`gsw-fr`)
- Occitan–French (`oci-fr`)
- Picard–French (`pcd-fr`).

## Licence
Please note that each language pair corpus has a different licence.
- Breton–French corpus: CC BY licence
